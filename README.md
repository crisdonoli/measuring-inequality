# Inequality in Chile: Methods in Practice

An applied, reusable codebase that shows how inequality is measured and corrected in
practice, from raw microdata to tail-corrected top shares:

1. clean a household survey and build a net-wealth variable,
2. compute survey-weighted percentile shares (bottom 50%, top 10%, top 1%),
3. correct the missing upper tail with the semi-parametric Pareto method of
   Vermeulen (2018), combining the survey with a rich list and anchoring financial
   assets to the National Accounts,
4. explore survey and tax tabulation inputs for the Blanchet–Flores–Morgan (2022)
   "merging point" method,
5. apply the BFM correction to CASEN income (2017 and 2022) using SII tax tabulations,
6. replicate Núñez and Miranda (2010) on intergenerational mobility: first-stage
   earnings equations, TSTSLS elasticities, rank-rank regressions by informality,
   and multiple imputation of paternal income and affiliation.

Each step is a self-contained notebook plus a function in `source/`, so the pieces can be
reused on other countries, years or surveys. The sequence of steps mirrors the
inequality problems in `documents/PS1_FPA.pdf`; it is not tied to that assignment.

## Requirements

- Python >= 3.10 with `pandas`, `numpy`, `scipy`, `matplotlib`, `scikit-learn`,
  `pyarrow`, `fastparquet`, `pyxlsb`, `openpyxl`, `jupyter`.
- R with `gpinter` installed in `.rlibs/` (gitignored). Download the `gpinter`
  source and run `R CMD INSTALL --library=.rlibs gpinter_<version>.tar.gz` once;
  `gpinter` is not on CRAN. If `gpinter` is unavailable, `bfm.py` falls back to
  linear interpolation with a warning.
- A LaTeX distribution with `latexmk`. All figures are compiled with
  `text.usetex = True` (`source/__init__.py`), so `pdflatex` must be on `PATH`;
  without it the plotting cells fail.

```bash
pip install -r requirements.txt
```

## Usage

Run the notebooks **in order** from inside `notebooks/` (`from utils import load_root`
relies on the working directory, and `load_root()` walks up to the directory containing
both `source/` and `data/`):

```bash
cd notebooks
jupyter lab          # or: jupyter notebook
```

### 1. `01_efh_cleaning.ipynb`: survey to net wealth

Loads `data/EFH/Base imputada EFH 2021.dta`, drops rows with missing `act_toth`,
`d_toth` or `factor`, and builds

```
net_wealth = act_fin + cap_pen_ent + (act_vp + act_otp + act_vevic + act_otros) - d_toth
```

Outputs `data/processed/efh_2021_clean.{csv,parquet}` and `figures/netwealth-efh.pdf`
(weighted vs. unweighted density, share of total wealth by bin).

### 2. `02_forbes.ipynb`: the rich list

Filters Chilean entries from the Forbes 2021 CSV, parses `NetWorth` (`'$17.7 B'` → `17.7`)
and converts to CLP at **759.1 CLP/USD**.
Outputs `data/processed/forbes_2021_clp.{csv,parquet}` and `figures/billionaires.pdf`.

### 3. `03_wealth_inequality.ipynb`: shares from the survey alone

Baseline: survey-weighted bottom-50 / top-10 / top-1 wealth shares
(`source.shares.weighted_shares`). This is the benchmark any correction has to beat.
Outputs `figures/p2/share.pdf`.

### 4. `04_vermeulen.ipynb`: Pareto tail correction

- estimates the Pareto tail index `alpha` above `w_min` with two methods: weighted MLE
  and the Gabaix–Ibragimov rank regression (`estimate_alpha_pareto`);
- shows sensitivity of `alpha` to `w_min` ∈ {380 M, 759.1 M, empirical p99}
  (`alpha_sensitivity.pdf`, `pareto_qq.pdf`);
- uprates `act_fin` so that the survey total matches the National Accounts financial
  assets aggregate, `426,112.5039` billions of CLP (`λ` = macro/survey);
- fills the gap between the richest EFH household and the poorest billionaire with
  conditional Pareto draws (`generate_pareto`, `seed=0`) and appends the Forbes
  observations (`vermeulen_correction`, final `alpha` from `w_min = 380 M`, MLE);
- reports raw vs. corrected shares and plots `shares_vermeulen.pdf`,
  `vermeulen_tail.pdf`.

### 5. `05_data_exploration.ipynb`: survey and tax inputs

- **CASEN**: loads 2017 and 2022, reports missingness across income variables, and
  motivates the choice of `ytotcorh` (total household income, corrected for
  non-response) over `yaut`/`yautcor` (31–44% missing). Collapses to one row per
  `folio+hogar` via `to_household` and saves `data/processed/casen_*_hh.parquet`.
- **SII**: parses `data/SII/PUB_Total.xlsb` (double header in rows 6–7) into tidy
  `cons_n`/`cons_renta` for the Consolidated block, writes BFM-ready
  `sii_{2017,2022}_tabulation.csv`, and plots brackets side by side across years
  (7 brackets in 2017 vs. 8 after the 2020 reform).

Outputs `figures/p3/casen_income_dist.pdf`, `casen_lorenz.pdf`,
`sii_brackets_comparison.pdf`.

### 6. `06_bfm.ipynb`: merging point and calibration

- Both distributions are expressed as annual income per adult:
  `ytotcorh * 12 / adultos(edad>=20)`, with effective weight `expr * adultos`.
  The count of adults per household is cached in
  `data/processed/casen_{year}_adults.parquet`; this step is required because
  SII tabulates taxpayers while CASEN tabulates households.
- Builds a 126-bin fractal grid with `_fractal_percentiles` /
  `fractal_percentiles_from`: 0–99% (1 pp), 99–99.9% (0.1 pp),
  99.9–99.99% (0.01 pp), 99.99–99.999% (0.001 pp).
- Interpolates the SII tabulation with `interpolate_tax_tabulation`, which calls
  `source/gpinter_bridge.R` (generalized Pareto interpolation via `gpinter`);
  without R the code falls back to linear interpolation with a warning.
- Bracket 1 is exempt, so `tax_quantiles` adjusts the fiscal CDF to start at
  `F_t(y2) = 1 - kappa + kappa*w1` (`_fiscal_p_start`), with `kappa` = 0.736
  (2017) and 0.763 (2022). The grid runs on `[F_t(y2), 1]`, leaving 45 bins
  (2017) and 46 bins (2022).
- `estimate_merging_point` returns `y*` = 68.0 M CLP/year (2017) and 190.0 M
  (2022).
- `calibrate_weights` rescales weights above `y*` to match the tax mass, with
  clip `alpha = 5`, using the same fiscal grid via `yk` / `tax_share` /
  `f_t_start`.
- `expand_support` maps quantiles preserving ranks over the fiscal support
  without changing total mass.
- Top shares (% of total income):

  | Method | 2017 Top 10 | 2017 Top 5 | 2017 Top 1 | 2022 Top 10 | 2022 Top 5 | 2022 Top 1 |
  |---|---|---|---|---|---|---|
  | Raw | 35.91 | 24.58 | 9.17 | 34.11 | 22.70 | 7.86 |
  | BFM | 40.16 | 29.27 | 13.56 | 35.43 | 24.12 | 9.40 |
  | BFM + expansion | 40.75 | 29.96 | 14.42 | 35.69 | 24.42 | 9.76 |

> **Caveat.** The public SII file reports only 7–8 brackets without decile
> detail, so the top 1% is identified directly in 2017 but in 2022 rests on
> 12 observations. In 2022 the required calibration factor (6.69) exceeds the
> `alpha = 5` clip, which understates the top 1% by ~0.8 pp; with `alpha >= 10`
> it converges to 10.19%.

### 7. `07_nunez_miranda.ipynb`: intergenerational mobility

Python replication of the R implementation (`MirandaNunez.Rmd`):

- **first stage** (Table A): OLS of log earnings on education dummies and an age
  profile, CASEN 1987 and 1990, HC1 standard errors;
- **TSTSLS** (Table 1): sons aged 25–40 in CASEN 2006, paternal income predicted at
  age 40 from retrospective schooling and occupation, with the Murphy–Topel
  correction;
- **rank-rank** (Tables 1B/1C): percentile ranks within age group, by sector
  (formal = contributing, informal = affiliated without contributions or unaffiliated);
- **multiple imputation** (Tables 1D/1E): bivariate lognormal income model plus a
  logistic affiliation model, `M = 100`, `ρ ∈ {0, 0.3, 0.6}`, Rubin's rules with
  Barnard–Rubin degrees of freedom.

Outputs `data/processed/mobility/*.csv`, `figures/p1/rank_sector.pdf` and
`figures/p1/sensibilidad_MI.pdf`.

## Method notes and caveats

- **Weights matter**: every share uses the survey weight `factor`; the denominator is the
  weighted sum of net wealth, so negative net wealth offsets positive holdings
  (see the report for why the Gini is unreliable in this case).
- **`w_min = 380 M CLP`** is not estimated: it is the threshold giving the best Pareto QQ
  fit and is hard-coded in notebook 04. `759.1 M` corresponds to the poorest Forbes
  billionaire (1 B USD at the 759.1 CLP/USD rate).
- **Hard-coded constants**: FX rate `759.1` (notebook 02) and the National Accounts
  financial-asset aggregate `426112.5039` bn CLP (notebook 04). Changing the data sources
  implies editing these values by hand.
- **Re-running notebook 04 mutates `efh_df`** (`act_fin` uprated, `net_wealth` recomputed
  as `act_toth - d_toth`). The uprating cell reloads the clean parquet when it detects a
  `λ` near 1 to avoid double counting, but after a full run re-execute the *Data load*
  cell before re-running downstream cells.
- **Pareto draws are seeded** (`seed=0`), but the correction is a simulation: shares move
  slightly if the row order or the number of draws changes.
- **Stata integer overflow**: in CASEN 1990 `edad` is stored as `int8`, so `edad**2`
  overflows. Always cast to float before squaring (`source/mobility.py`).
- **Missing occupation is not zero**: in R, `as.integer(ocup == k)` returns `NA` when
  `ocup` is missing, and `lm`/`glm` drop those rows (N = 20,354 instead of 20,387 in
  1990 with occupation). The Python code preserves the `NaN` and drops the same rows.
- **Multiple imputation uses a different RNG engine** than the R reference, so slopes
  match within Monte Carlo error (max difference ≈ 0.007 on slopes of ≈ 0.2–0.7) rather
  than exactly. The data-generating process is identical.
- **Sensitivity to `kappa`**: the BFM top-1% share in 2017 moves from 10.93% to
  13.56% as fiscal coverage `kappa` ranges from 0.40 to 0.736. `y*` and the
  resulting shares depend on `kappa`, which should be cross-checked against
  external population estimates (INE).
- Raw inputs are not regenerated by the pipeline; `data/EFH/`, `data/Forbes/`,
  `data/CASEN/` and `data/SII/` must be obtained from their original sources
  (links in the notebooks).

## Report

```bash
cd documents/report

```

`main.tex` compiles three sections: `sections/01.tex` (intergenerational mobility),
`sections/02.tex` (wealth inequality with the Vermeulen correction) and `sections/03.tex`
(BFM method, data and results), plus the appendix/conclusions. Figures are included with paths
